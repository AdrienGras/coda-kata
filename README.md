## 🚀 Run the Code

**Pick your kata:** Dive into the folder.

### 🦀 For Rust-based projects

**Run the tests:**
```bash
cargo test
```

**For the visual pros:** Use nextest for a sleeker testing experience:

```bash
cargo nextest run
```
